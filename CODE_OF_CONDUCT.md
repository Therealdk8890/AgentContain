# Code of Conduct

## Our commitment

WarrantKit is an open-source security project. We are committed to providing a respectful, constructive environment for contributors, maintainers, users, and reviewers.

Participants are expected to communicate professionally, assume good faith, focus criticism on technical work rather than people, and respect different backgrounds and levels of experience.

## Unacceptable behavior

Unacceptable behavior includes harassment, discrimination, personal attacks, threats, deliberate disruption, doxxing, sexualized harassment, and publishing private or confidential information without authorization.

Security-sensitive discussion should follow `SECURITY.md` rather than exposing exploit details in public issues or pull requests.

## Maintainer response

Project maintainers may remove comments, close discussions, reject contributions, or restrict participation when necessary to keep project spaces safe and constructive.

Security reports are handled according to `SECURITY.md`.

## Scope

This code of conduct applies to project spaces and interactions where participants are representing or materially participating in WarrantKit.

## Reporting

For conduct concerns, contact the project maintainer privately through the contact information published in the repository profile or project documentation. For security vulnerabilities, use the private reporting process in `SECURITY.md`.

This document is intended to establish a practical baseline for participation; it does not limit any contributor's rights under applicable law.
